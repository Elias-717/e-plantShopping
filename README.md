# Paradise Nursery

Paradise Nursery is a React plant shopping application with Redux-powered cart management.

## Features

- Browse plants by category.
- View plant images, descriptions, and prices.
- Add plants to the cart.
- See the live total item count in the cart icon.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View item subtotals and the total cart amount.
- Continue shopping from the cart.
- GitHub Pages deployment support through `gh-pages`.

## Run Locally

```bash
npm install
npm run dev
```

## Build and Deploy

```bash
npm run build
npm run deploy
```

The application uses React, Redux Toolkit, React Redux, and Vite.
